## Before you start

:::note[You need]
A GitHub organization with private repositories, and an x64 Linux machine
with KVM, 4 cores, 16 GB of memory, and 250 GB of disk or more.
:::

## Set up ciproxy

1. ### Sign in and install the GitHub App

   [Sign in to ciproxy](https://app.ciproxy.dev/sign-in) with GitHub. Then
   install the ciproxy GitHub App on your organization, and pick the
   repositories that may use it. If you are not an owner of the
   organization, GitHub sends your request to its owners.

   The person who installs the App becomes the first Admin of the new
   workspace. When an owner approves the request of a member, the member
   who asked becomes the first Admin.

2. ### Add a machine

   In ciproxy, Setup shows the install command. You also find it in
   **Machines**, under **Add machine**. Run the command on your Linux
   machine:

   ```sh title="Terminal"
   curl -fsSL https://get.ciproxy.dev | sudo sh -s -- install --token <install token>
   ```

   The command holds a token for your workspace, which works for one hour.
   When the machine connects, ciproxy shows it with its slots.

3. ### Connect Boat

   To start jobs on Boat when your machines are full, connect your Boat
   account in Setup, or in **Settings** under **Overflow**. Give an API key
   of your Boat account and a monthly spend limit. You can connect Boat
   later.

4. ### Change runs-on

   In a workflow file, change the `runs-on` line of a job:

   ```diff lang="yaml" title=".github/workflows/ci.yml"
    jobs:
      test:
   -    runs-on: ubuntu-latest
   +    runs-on: ciproxy
        steps:
          - uses: actions/checkout@v4
          - run: cargo test --workspace
   ```

5. ### Push the change

   Push to GitHub. The job runs on your machine, at once when a warm runner
   is ready. **Jobs** in ciproxy shows where it ran, and how long it waited.
